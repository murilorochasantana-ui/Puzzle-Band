# Puzzle Band — app do cuidador (Flutter)

App Android que mostra o estado da criança ao vivo, notifica os alertas e
mostra o histórico. Recebe tudo da pulseira pelo broker MQTT (o painel do
site é opcional).

Configurar (`env.json`), rodar no emulador ou no celular, telas e
limitações: [../docs/app.md](../docs/app.md). Tópicos e mensagens:
[../docs/mqtt.md](../docs/mqtt.md).

Telas originais: [mariafernandarsantos/puzzleband](https://github.com/mariafernandarsantos/puzzleband).
